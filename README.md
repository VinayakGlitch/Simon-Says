# Simon Says Game

A simple browser-based **Simon Says memory game** built using **HTML, CSS, and JavaScript**.

The game generates a sequence of colored buttons that the player must remember and reproduce in the correct order. With every successful round, the sequence gets longer and the difficulty increases.

## 🎮 Features

* 🎯 Randomly generated color sequences
* 🧠 Increasing difficulty with every level
* ⚡ Visual flash animation for game-generated sequences
* 👆 User click animation
* 💀 Game-over detection when the wrong button is pressed
* 🏆 Highest score tracking
* 🔄 Automatic reset after game over
* 🎲 Four different colored buttons
* 📱 Simple responsive-friendly layout

## 🛠️ Tech Stack

* **HTML5** — Structure of the game
* **CSS3** — Styling and animations
* **JavaScript** — Game logic and state management

## 🕹️ How to Play

1. Open the game in your browser.
2. Press **any key** to start.
3. Watch the button that flashes.
4. Click the same button.
5. The game adds another button to the sequence.
6. Repeat the **entire sequence in the correct order**.
7. One wrong click ends the game.
8. Try to beat your highest score.

## 🧠 How the Game Works

The game maintains two arrays:

```javascript
let userSeq = [];
let gameSeq = [];
```

### `gameSeq`

Stores the sequence generated by the game.

Example:

```javascript
["red", "purple", "green"]
```

### `userSeq`

Stores the buttons clicked by the player.

Example:

```javascript
["red", "purple", "green"]
```

The two sequences are compared after every click.

```javascript
if (userSeq[idx] === gameSeq[idx]) {
    // Correct
} else {
    // Game Over
}
```

### Level Progression

Every time the player successfully reproduces the complete sequence:

```javascript
setTimeout(levelUp, 600);
```

`levelUp()` adds one new random color to `gameSeq`.

```javascript
let randidx = Math.floor(Math.random() * btns.length);
let randColor = btns[randidx];

gameSeq.push(randColor);
```

Therefore, the sequence becomes longer after every successful level.

## 🏆 Score System

The current level is used as the player's score.

The highest score is stored in:

```javascript
let highestScore = 0;
```

Whenever the player reaches a new level:

```javascript
if (highestScore < level) {
    highestScore = level;
}
```

The highest score remains visible even after the current game ends.

## 🎨 Button Flashing

Two CSS classes are used for visual feedback.

### Game Flash

```css
.change {
    background-color: beige;
}
```

Applied when the game shows the player which button to remember.

### User Flash

```css
.userflash {
    background-color: grey;
}
```

Applied when the player clicks a button.
